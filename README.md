# Rapor Asrama

Repositori ini adalah aplikasi web untuk menampilkan laporan/rapor penilaian santri atau anggota asrama (awalnya digunakan untuk Asrama Salman ITB). Aplikasi ini membaca data dari Google Spreadsheet, lalu dikelola menggunakan infrastruktur Edge/Serverless untuk kecepatan maksimal.

## Panduan Memulai

Jika Anda adalah fasilitator/pengelola baru yang ditugaskan untuk mengelola proyek ini:
1. Bacalah [HANDOVER-GUIDE.md](./HANDOVER-GUIDE.md) untuk langkah-langkah *setup* dan *re-deploy* secara lengkap.
2. Untuk memahami bagaimana struktur dan arsitektur kode di belakangnya, bacalah [SYSTEM-ARCHITECTURE.md](./SYSTEM-ARCHITECTURE.md).
